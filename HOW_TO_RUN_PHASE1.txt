============================================================
               Phase 1: Spec-Driven Todo
============================================================

Commands:
  add task: <title>    - Create new todo
  list                 - Show all todos
  complete <id>        - Mark todo as done
  exit                 - Quit application

-----------------------------------------
4. COMMAND REFERENCE
-----------------------------------------

ADD TASK:
  add task: <your task here>
  create task: <your task here>
  new task: <your task here>

LIST TASKS:
  list
  list tasks
  show tasks

COMPLETE TASK:
  complete <id>
  done <id>
  finish <id>

EXIT:
  exit
  quit
  q
  (or press Ctrl+C)

-----------------------------------------
5. TROUBLESHOOTING
-----------------------------------------

If you see "python3: command not found":
  → Try: python phase1/app/main.py

If you see import errors:
  → Make sure you're in the repo root directory
  → Run: pwd (should show ...in-memory-python-console-app)
